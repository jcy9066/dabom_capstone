4. Initial Pose

저장 지도·현재 Mapping의 새 관측 재시도, 클릭·드래그, AMCL 복수 관측 확인. 능동 회전 코드는 Pi-local 100ms/PWM20%·STOP/Encoder 검증으로 반영됐지만 실기기 검증 전에는 PASS로 처리하지 마세요

ros2 topic echo /amcl_pose --once
ros2 run tf2_ros tf2_echo map base_link

정상 결과 / 실패 시 확인: 저장 지도 미리보기 클릭·드래그, 3D Viewer SET INITIAL POSE, 지도 밖·Occupied 차단, Unknown 경고 승인, 지도 버전 일치, AMCL 복수 관측 검증. 고정 (0,0,0)이나 단일 AMCL 응답을 성공으로 판정하면 FAIL. 자동 능동 회전은 코드 반영·실기기 미검증. 회전 전/후 STOP ACK·Encoder 정지·Odometry 방향/각도·Pi 안전 세대 확인
