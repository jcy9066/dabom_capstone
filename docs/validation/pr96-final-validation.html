2. Mapping

SLAM Toolbox의 /map 발행 및 저장 확인

ros2 topic hz /map
ros2 run tf2_ros tf2_echo map base_link

정상 결과 / 실패 시 확인: /map 실제 메시지가 증가해야 하며 Preview만 보이면 실패. TF 오류 시 센서 시간 정합과 SLAM 상태 확인

3. 회전 및 Ghost Obstacle

90°·180°·360° 회전 시 고정 장애물 세계 좌표 확인

ros2 topic echo /scan --once

정상 결과 / 실패 시 확인: 장애물의 지도 좌표 고정, Live Scan은 매 관측마다 교체. 실패: TF timestamp, /odom yaw, costmap clearing 구분

정상 결과 / 실패 시 확인: 불확실한 추정 및 지도 밖 좌표는 자동 수락하지 않아야 함. 실패: AMCL covariance, 로봇 정지 상태, 최신 LiDAR/Encoder 확인
